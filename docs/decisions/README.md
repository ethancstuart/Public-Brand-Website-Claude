# Decision log

Decisions that shaped this repo, with the reasoning that produced them. Kept
because the site claims it — *"PRDs, decision logs, and conventions live in the
repo with the code they govern"* — and a claim you can't check is worth nothing.

One file per decision, numbered, newest last. A decision goes here when it will
outlive the person who made it and would otherwise be re-litigated.

Format: context → decision → why → consequences. Record decisions that were
**rejected** too; the rejected option is usually what a future session tries first.
